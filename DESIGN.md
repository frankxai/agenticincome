# AgenticIncome Design System

## First Read

AgenticIncome builds revenue systems with agents and hands them over with repository, verification, and preview evidence.

## Brand World

FrankX technical luxury: obsidian foundation, emerald implementation signal, amber commercial signal, precise typography, quiet grids, and dense proof surfaces. The page should feel like a serious build room, not a trading dashboard or generic AI SaaS template.

## Tokens

- Background: `#05060A`
- Surface: `#0A0C14`
- Border: `#1A1F2E`
- Ink: `#F1F3F9`

- Implementation accent: `#10B981`
- Technical secondary: `#06B6D4`
- Commercial signal: `#F59E0B`

## Composition

- One dominant implementation claim in the first viewport.
- Tier C coded product proof is the primary hero asset.
- Real public repositories and the live routing directory are the proof rail.
- Body content alternates quiet editorial space with dense mechanism surfaces.
- Glass is reserved for navigation, implementation, and evidence controls.

## Motion

The signature behavior is Audit, Architect, Implement, Verify. Motion reveals causality; reduced motion shows the same complete static sequence.
