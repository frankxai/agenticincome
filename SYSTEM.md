# AgenticIncome Product System

## Product Role

AgenticIncome is the HUB of the Agentic Income Trinity (EARN → agenticpassiveincome AUTOMATE → dpi COMPOUND) — the education-first, open-core surface where a creator goes from capability to cash flow.

1. Open core: the `knowledge/` base (dated, quarterly re-verified) and the installable `/ai` Income Architect pack (commands, agents, skills — Claude Code plugin + portable layer).
2. Digital products: Starter Kit (free), Income Architecture Blueprint ($67), Agent Team Pro ($129), Private Intel ($19/mo) — self-serve via merchant of record.
3. Agent-as-a-Service: scoped audit, architecture, implementation, verification, and handoff (apex, 2/month).
4. Editorial/affiliate: reader-first comparisons with disclosed incentives, freshness evidence, and the go.agenticincome.ai router.

Strategy contract: `STRATEGY.md` (property) and the trinity master plan (operator workspace).
