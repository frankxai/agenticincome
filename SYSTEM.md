# AgenticIncome Product System

## Product Role

AgenticIncome is the canonical commercial revenue-engine surface in the FrankX estate.

1. Agent-as-a-Service: scoped audit, architecture, implementation, verification, and handoff.
2. Digital products: Starter Kit, Blueprint, and Private Intel.
3. Open source: installable skills, catalog/audit engine, and deployable template.
4. Editorial/affiliate: reader-first comparisons with disclosed incentives and freshness evidence.

## Application

- Next.js 16 App Router, React 19, TypeScript, Tailwind 4, and MDX.
- GSAP is limited to authored hierarchy and mechanism motion.
- Local catalog data is vendored; production builds must not depend on sibling repositories.
- Vercel project: `agenticincome` (`prj_h8sRP6o1Q16RIgznvD2VtFPaZgV4`).
- GitHub repository: `frankxai/agenticincome`.

## Revenue Readiness

- Starter Kit is delivered on-site.
- Implementation Sprint is scope-first and takes no payment on the site.
- Blueprint and Private Intel remain request-access routes until provider URLs exist.
- Email intake claims receipt only when a configured destination can retain it.
- No revenue or customer outcome is promised.

## Release Contract

Frozen install, type check, link check, build, source security scan, visual inspection, evidence validation, Git-backed preview, and residual-risk handoff are required before production consideration.
