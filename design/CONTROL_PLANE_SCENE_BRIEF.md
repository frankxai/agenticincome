# AgenticIncome Control-Plane Scene Brief — 2026-07-13

## Creative thesis

Economic control is made visible through artifacts and authority boundaries. The experience feels like a serious build room: restrained obsidian surfaces, emerald implementation signal, amber approval signal, and exact language.

## Signature interaction

The Request-to-Quote desk transforms a customer request into a reviewable Markdown brief entirely in the browser. The artifact names allowed preparation work and forbidden commitment actions.

## Static state

All route meaning is available without JavaScript except the local artifact generation. Without an artifact, the desk presents an explicit empty state and privacy boundary.

## Asset decision

Tier C system-authored UI. No generated imagery, decorative dashboard, revenue chart, or unsupported customer evidence is introduced.
