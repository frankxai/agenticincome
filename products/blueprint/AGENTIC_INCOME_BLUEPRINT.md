# Agentic Income Blueprint

## Promise

Install the operating desk for turning AI-tool comparison demand into a reusable recommendation asset, recurring-payer route, owned audience, and direct product path.

## Buyer

Creator operators and founder-led publishers who want a practical system instead of scattered notes.

## First Win

Publish one citable comparison with:

- direct answer
- comparison table
- honest pick
- alternatives
- disclosure
- recurring-payer route
- email capture
- product upgrade path

## Desk Modules

### 1. Search Intent Map

Pick one AI-tool category where users already compare options, switch tools, and make buying decisions.

Template:

```text
Category:
Primary query:
Buyer state:
Current tool set:
Pain:
Best-fit reader:
Tools to test:
Payer routes:
```

### 2. Recommendation Rule

The answer must survive disclosure. Use this order:

1. best fit for the reader
2. real tradeoffs
3. current payer route
4. affiliate disclosure
5. next useful step

### 3. Comparison Page Shape

```text
Short answer
Best overall
Best for specific use case
Comparison table
Why the winner wins
Where the winner is weak
Alternatives
Pricing and affiliate disclosure
FAQ
Next step / capture
```

### 4. Recurring-Payer Catalog

Track:

- tool
- category
- commission
- recurring status
- cookie window
- payout terms
- join status
- approved tracking link
- notes from real use

### 5. Owned-Audience Capture

The capture promise should finish the reader's workflow:

- current payer shortlist
- comparison checklist
- first-loop sprint
- stack update notes

Avoid vague newsletters.

### 6. Weekly Cadence

Every week:

1. publish or refresh one comparison
2. audit payer routes
3. add one capture improvement
4. review one product upgrade path
5. update the catalog note

## Support Boundary

This product includes template-level support and update notes. It does not include private implementation consulting.
