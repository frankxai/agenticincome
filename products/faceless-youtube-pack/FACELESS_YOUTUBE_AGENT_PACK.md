# Faceless YouTube Agent Pack

## Promise

Give your agent the exact prompt chain to research, script, voice, assemble, and publish a faceless YouTube video end to end — without you touching video editing, scriptwriting, or voice work.

## Buyer

Creators and side-income builders who want the outcome (a running channel) without becoming an editor. Adjacent to Blueprint buyers, but earlier-stage — they want one working channel before they want the operating desk.

## Price

$97 launch / $149 standard. One-time. No recurring obligation on our side — the pack is prompts and a workflow map, not a hosted service.

## First Win

Produce one published video with: a validated title, a hook-heavy script, generated voiceover, assembled visuals, and full upload metadata — using nothing but the four prompts below and tools the buyer already can sign up for.

## Pack Modules

### 1. Niche Research Agent (prompt)

Role: turn a broad channel niche into 10 low-competition, high-intent video titles per week.

```text
Input: channel niche, target audience, 3 competitor channels
Output: 10 titles ranked by (search intent strength × competition gap),
        one target keyword per title, one differentiation angle per title
```

Deliverable: copy-paste prompt + a tracking sheet template (title, keyword, status, publish date).

### 2. Scriptwriter Agent (prompt)

Role: turn one title into a high-retention script built for faceless pacing.

Enforces: **Hook → Value → Tease → Value → CTA**, explicit B-roll callouts every 15–20 seconds, no filler sentences, cold open under 8 seconds.

Deliverable: prompt chain + one worked example script so the buyer can see the target shape before running their own.

### 3. Audio/Visual Assembly Workflow (blueprint, not code)

Role: connect the finished script to voice generation and visual assembly using tools the buyer signs up for directly — this pack never touches their API keys or hosts anything.

- **Voice:** ElevenLabs — script in, narration out. (22% commission, 90-day cookie, our audited pick — see [go.agenticincome.ai/elevenlabs](https://go.agenticincome.ai/elevenlabs))
- **Visual assembly / B-roll:** Higgsfield or CapCut, depending on budget. Higgsfield for AI-generated B-roll from the script's callouts; CapCut for stock + template assembly. (Higgsfield 15% ambassador; CapCut up to 35% — both recurring)
- **Long-form → Shorts repurposing (optional):** Opus Clip turns the finished video into 3–5 vertical clips for distribution.

Deliverable: a step-by-step assembly map (not a Zapier/API integration — the buyer runs each tool manually or via that tool's own automation, keeping this pack liability-free on our side).

### 4. Publishing & SEO Agent (prompt)

Role: turn the finished script into the full YouTube metadata package.

```text
Input: final script, target keyword
Output: title (3 variants), description (with timestamps), 15 tags,
        pinned comment copy, community-post copy
```
