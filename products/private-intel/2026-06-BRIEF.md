# Private Intel Brief

Date: 2026-06-26

## Thesis

The durable opportunity is not "AI tools" broadly. It is maintained comparison memory around tools with recurring economics, real switching pain, and clear buyer intent.

## Watchlist

| Route | Why it matters | Action |
|---|---|---|
| Voice/video production stacks | Creator buyers compare tools often and tolerate paid subscriptions | Keep ElevenLabs, CapCut, Descript, and related routes audited |
| AI coding assistants | High switching intent and subscription budgets | Build comparison pages by user type, not generic "best" lists |
| Workflow automation | Buyers want stack architecture, not one tool | Package comparison + implementation checklist |
| Local/private AI tools | Trust, privacy, and ownership are rising concerns | Track programs carefully; many tools will not have strong affiliate routes |

## Monthly Operating Question

Which page would still be useful if every affiliate program disappeared tomorrow?

That page gets built first.

## Catalog Audit Notes

- Prefer recurring revenue only when the product is honestly recommendable.
- Mark pending programs separately from active tracking links.
- Re-check terms before publishing because program rules change.
- Do not let payout percentage outrank product fit.

## Suggested Move

Build one high-intent comparison for a creator workflow, then add a Starter Kit capture that helps the reader choose the next tool without forcing a purchase.
