# Agentic Income Starter Kit

Use this kit to build the first complete revenue loop:

1. one search-intent question
2. one honest comparison
3. one recurring-payer route
4. one owned-audience capture
5. one next product step

## The 30-Minute Sprint

### 00-05: Choose A Category

Pick one AI-tool category you have touched directly:

- AI video
- AI voice
- faceless YouTube
- coding agents
- writing systems
- automation agents

The category must have real search demand and at least one tool with a recurring-payer route.

### 05-12: Name The Query

Use one of these shapes:

- best AI tool for [specific workflow]
- [tool A] vs [tool B]
- is [tool] worth it
- [tool] alternatives
- best [workflow] stack under [budget]

Write the query as a human would ask it. Do not start with the affiliate program.

### 12-20: Draft The Comparison Shape

Use this page structure:

- short answer
- quick comparison table
- honest pick
- who should choose each option
- recurring-payer route if it fits
- disclosure
- FAQ
- email capture promise

The recommendation has to survive the sentence: "Some links may pay us, but the best-fit tool still wins."

### 20-25: Route The Payer

Check the catalog:

- Does the tool have a real program?
- Is the commission recurring?
- Is the cookie window reasonable?
- Does the payout match the recommendation?
- Is the link live or pending?

If no payer fits, publish the truth and capture the audience instead.

### 25-30: Capture The Relationship

Use an email promise tied to the workflow:

- "Get the updated payer shortlist."
- "Get the first comparison outline."
- "Get the stack checklist."
- "Get the monthly payer brief."

Avoid vague newsletter language.

## First Loop Checklist

- [ ] Category chosen from real experience
- [ ] Search query written plainly
- [ ] Honest short answer drafted
- [ ] Comparison table planned
- [ ] Disclosure included
- [ ] Recurring payer checked
- [ ] Email capture promise written
- [ ] Next product step selected

## Revenue Rule

Affiliate funds the floor. Owned audience and direct products create the durable asset.

Best fit first. Payout second. Trust compounds.
